## 🧠 Sobre o Projeto

O **Vigilante de Gastos** é uma aplicação web moderna voltada para gestão pessoal de finanças.  
Foi desenvolvida para oferecer **visão analítica**, **simplicidade de uso** e uma **experiência visual imersiva**.

> 💡 O objetivo é transformar o acompanhamento financeiro em algo visualmente prazeroso e eficiente.

---

## 🚀 Funcionalidades Principais

- 📊 **Dashboard interativo** com visão consolidada de despesas e receitas.  
- 💰 **Classificação automática de gastos** por categoria.  
- 🧾 **Histórico detalhado** de transações com filtros dinâmicos.  
- 🎯 **Metas e alertas personalizados**.  
- ☁️ **Autenticação segura** (Google, GitHub e credenciais locais).  
- 🔒 **Controle de permissões** por nível de acesso (Admin / Usuário).

---

## 🧩 Stack Tecnológica

| Camada | Tecnologia |
|--------|-------------|
| **Frontend** | React + Vite + Tailwind + Shadcn UI |
| **Autenticação** | Firebase Auth (Google, GitHub, E-mail/Senha) |
| **Banco de Dados** | Firestore / Supabase |
| **Gráficos** | Recharts + Custom Components |
| **Infraestrutura** | Firebase Hosting / Vercel |
| **Design System** | Custom Theme inspirado no Sapphire UI Dark |

---

## 🖌️ Tema Visual

- 🎨 **Paleta**: tons escuros de cinza, roxo e violeta.  
- 🌌 **Mood**: futurista, analítico e minimalista.  
- 🧭 **Tipografia**: Inter / JetBrains Mono (para números e dashboards).  
- ✨ **Elementos**: cards flutuantes, glow roxo, cantos arredondados e gradientes sutis.
